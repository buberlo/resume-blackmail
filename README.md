# Resume Blackmail

> Your CV negotiates with recruiters until they offer coffee money.

A web app where you upload a resume and it impersonates your career history in a slow negotiation with a recruiter persona. The resume starts confident, then asks for perks like no-meeting Wednesdays and remote Fridays as its fatigue meter rises. It sends polite but passive-aggressive follow-ups when the recruiter stalls and keeps a receipt of every concession.

## Features
- Upload a resume and set a salary target plus non-negotiables
- Generate recruiter-style negotiation emails with a visible fatigue meter
- Simulate recruiter replies to test your resume's patience
- Export a concession ledger and send one passive-aggressive follow-up email

## Stack
- Next.js
- OpenAI
- Resend
- Supabase

## Getting started
```
npm install && cp .env.example .env.local && npm run dev, then open http://localhost:3000.
```
